## Conflicting guidance and standards boundaries

- Beck explicitly distinguishes canonical incremental TDD from writing all runnable tests up front. Toque may deliberately use batch test-first work, but comparative superiority is untested. Thoughtworks’ 2023 Assess entry supports experimenting with AI-aided test-first work, not an industry mandate for Toque’s batch ordering.
- Separate test authoring and isolated review can expose different errors but do not create statistically independent evidence when models, context and files overlap. Toque contains contradictory writer instructions.
- DORA now names five metrics; stage timestamps and incident counts are not equivalent measurements. The former grade/color thresholds have no demonstrated predictive calibration.
- Google SRE prioritizes restoration during incidents while testing hypotheses for diagnosis. Toque’s temporary containment exception is compatible with that distinction; automatically trusting a historically similar fix would not establish cause.
- A publisher page credits Feathers but does not verify inaccessible book passages. Cucumber supports collaborative acceptance examples, not proof of a distinct Toque ATDD execution branch.
- Node’s release page supersedes interpreting a compatibility floor of 18+ as a current supported-production recommendation. No runtime matrix across all Node lines was run.
